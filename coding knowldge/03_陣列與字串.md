# 陣列與字串

## index 邊界

陣列長度是：

```java
nums.length
```

最後合法 index：

```text
nums.length - 1
```

如果有 `i + 1`，要先確認：

```java
i + 1 < nums.length
```

如果有 `i + j`，要確認：

```java
i + j < length
```

## Remove Element 類型

核心變數：

```text
j：掃描所有元素
i / k：下一個保留元素要放的位置
```

遇到要保留的元素：

```java
nums[i] = nums[j];
i++;
```

重點：

```text
不是只計數，還要把保留元素搬到前面。
```

## Merge Sorted Array 類型

如果從前面插入，會需要搬移元素，容易覆蓋資料。

重要觀念：

```text
nums1 後面本來就有空位，可以從後面開始放最大值。
```

三個指標：

```text
i：nums1 有效元素最後一格
j：nums2 最後一格
k：nums1 整個陣列最後一格
```

## 字串比對

像第 28 題 Find First Occurrence：

```text
i：haystack 的候選起點
j：needle 的目前比對位置
```

比對公式：

```java
haystack.charAt(i + j) == needle.charAt(j)
```

外層最後合法起點：

```java
haystack.length() - needle.length()
```

所以通常要用：

```java
i <= haystack.length() - needle.length()
```
