# 常見錯誤清單

## 迴圈沒有改變條件變數

例子：

```java
while (i < j) {
    // 但 i 和 j 都沒有變
}
```

這會造成無限迴圈或 TLE。

## mid 只算一次

Binary Search 裡，`mid` 要每一輪重新計算。

錯誤：

```java
int mid = (left + right) / 2;
while (...) {
    ...
}
```

應該在 while 裡算。

## 讀 null 的 val

Linked list 裡：

```java
current.next.val
```

前提是：

```java
current.next != null
```

如果還要讀：

```java
current.next.next.val
```

前提是：

```java
current.next != null
current.next.next != null
```

## 回傳 current 而不是 head

`current` 通常已經走到中間或尾巴。

如果要回傳整條 list，通常回傳：

```java
head
```

或：

```java
dummy.next
```

## 建立 result 但沒有寫回目標

有些題目是 `void`，例如 Merge Sorted Array。

LeetCode 會檢查傳進來的陣列本身。

如果只建立：

```java
int[] result = new int[...];
```

但沒有寫回 `nums1`，LeetCode 看不到。

## index 越界

最後合法 index：

```text
length - 1
```

如果要用 `x + 1`，條件不能讓 `x + 1 == length`。

## 型別混淆

`ListNode` 是節點。

`ListNode.val` 才是 int。

錯誤：

```java
int repeat = current.next;
```

正確：

```java
int repeat = current.next.val;
```

## 中文符號混入程式

例如：

```java
int repeat = current.next.val。;
```

中文句號 `。` 會讓 Java 編譯失敗。
