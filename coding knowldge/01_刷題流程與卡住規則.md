# 刷題流程與卡住規則

## 我目前的問題

- 看題目後容易直接想寫 code，沒有先翻譯題目。
- 卡住時會在腦中空想太久。
- 一題卡太久後容易分心，轉去做別的事。
- 常常想問下一步，而不是先產出自己的完整嘗試。

## 每題固定流程

```text
1. 題目翻譯
2. 手算範例
3. 寫出變數責任
4. 寫第一版 code
5. 跑測資
6. 記錄錯誤
```

## 25 分鐘規則

```text
0～5 分鐘：只翻譯題目
5～10 分鐘：只手算範例
10～15 分鐘：只寫變數責任
15～25 分鐘：寫第一版 code
25 分鐘後：整理卡點再問
```

卡住時不能換題、不能滑手機、不能開新東西。

只能做：

```text
畫圖
手算
寫下卡在哪
```

## 問問題前要貼

```text
題目：
我翻譯成：
範例手算：
我覺得需要的變數：
我的程式碼：
錯誤結果：
我猜問題在：
我卡在：
```

## 完成一題的標準

不是只有 Accepted 才算完成。

真正完成代表：

- 我能說出題目在問什麼。
- 我能手算至少一個例子。
- 我知道每個變數的責任。
- 我知道迴圈條件為什麼這樣寫。
- 我知道至少兩個邊界測資。
- 我能說出自己原本錯在哪。
