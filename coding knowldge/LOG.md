# 提示等級紀錄

## 唯一一條規則

問 AI 之前，先決定我要領第幾級。一次只能領一級。

| 級 | AI 只能給我 |
|---|---|
| L0 | 什麼都沒給，自己解出來 |
| L1 | 只講類別名（雙指標 / HashMap / 遞迴…），不解釋 |
| L2 | 一句話講關鍵觀察 |
| L3 | pseudocode 骨架，不含 Java |
| L4 | 完整解法 → 本題算「未學會」，7 天後重做 |

不算提示、隨時可問：Java 語法、「這行的 i 是多少」、「我的想法對不對，只回答對/錯」。
