# 頁面1
父子類別的繼承
class Sup{...}
class sub extends Sup{...}
#### 建立
`Sup psup1 = new Sup();` 
`Sub psub1 = new Sub();`
`Sup psup2 = new Sup();`
`Sub psub2 = new Sub();`

1.
同類別的物件地址可以設入指標中
如：`psup1 = psup2;、psub1= psub2`。
2.
不同類別只能下往上，如psup1 = psub2，不會自廢武功。
假設今天有一個類別父類別XY() X and Y，及子類別WXY()能使用WXY功能，但如果我們要讓父類別物件地址XY()設入WXY()中，W就拿不到了系統就會報錯。
但可以使用down-cast設入，如psub1 = (sub)psup2;
執行會檢查父類別是否真的指向子類別物件，若是就能成功編譯，否則發生java.lang.ClassCastException
3.
傳參數也遵守同樣規則
如：
`void f(sup psup){...}`
`void g(sub psub){...}`
`sup psup2 = new sup();`
`sub psub2 = new sub();`
`f(psup2)//合法，父放入父`
`g(psub2)//合法，子放入子`
`f(psub2)//合法，子放入父`
g(psup2)//==不合法，父放入子==，但一樣可以用向下轉型法down-cast
this參數同樣規則
