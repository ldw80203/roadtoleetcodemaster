# 四問：array / string 的思考框架

樹題用三格，array/string 用四問。這份是「怎麼填」的說明書。

---

## 為什麼需要它

你診斷測五題全部 O(n²)，不是因為想不出來，是因為**直接跳進去寫迴圈**。
沒有先講清楚「每個變數代表什麼」，就只能靠「多包一層迴圈掃過所有可能」。

四問就是逼你在寫第一行之前，把迴圈的規格講清楚。

---

## 第 1 問：我開了哪些變數／指標，每一個代表什麼

**要求：每個變數都要有一句「代表什麼」的中文。不能只寫用途，要寫「它此刻的意義」。**

不好的填法：
- `i 是迴圈變數` ← 廢話
- `max 用來存最大值` ← 太模糊，哪個範圍的最大值？

好的填法：
- `i：目前要檢查的位置`
- `max：nums[0] 到 nums[i-1] 這段裡面的最大值`
- `slow：下一個「該放非零值」的位置`
- `sum：目前窗口 nums[left..right] 的總和`

注意好的填法都帶了**範圍**。帶範圍的描述才有用，因為它直接變成第 2 問。

---

## 第 2 問：迴圈不變式（最重要的一問）

### 定義

**每一輪迴圈開始的那個瞬間，有一句話一定是真的。這句話就是不變式。**

它不是「迴圈做什麼」，是「迴圈跑到這裡為止，已經保證了什麼」。

### 三個必須成立的檢查

一個正確的不變式要通過三關：

1. **一開始就成立**（進迴圈前，第一輪還沒跑，它就是真的）
2. **每一輪跑完還是成立**（迴圈本體的工作就是「維持它」）
3. **迴圈結束時，它 + 結束條件 = 答案**

第 3 關是重點。你在樹題犯的「回傳值 ≠ 答案」，在這裡就是「不變式跟答案接不起來」。

### 範例 A：求陣列最大值（單指標）

```java
int max = nums[0];
for (int i = 1; i < nums.length; i++) {
    if (nums[i] > max) max = nums[i];
}
return max;
```

四問：

1. `i`：目前要檢查的位置。`max`：`nums[0..i-1]` 的最大值
2. **不變式：每輪開始時，`max` 等於 `nums[0..i-1]` 裡的最大值**
3. `i` 從 1 開始（因為 `max` 已經吃掉 `nums[0]`），`i < nums.length`，用 `<`
4. 結束時答案在 `max`

驗三關：

- 一開始 `i=1`，`max=nums[0]`，而 `nums[0..0]` 的最大值就是 `nums[0]` ✓
- 每輪把 `nums[i]` 比進去、`i++`，所以下一輪開始時 `max` 是 `nums[0..i-1]` 的最大 ✓
- 結束時 `i == nums.length`，不變式說 `max` 是 `nums[0..length-1]` 的最大＝全部的最大 ✓

第三關通過，所以 `return max` 是對的。這就是「證明自己寫對了」的方法，不用靠送出去試。

### 範例 B：移除所有等於 val 的元素（快慢指標，就是你做過的 27）

```java
int slow = 0;
for (int fast = 0; fast < nums.length; fast++) {
    if (nums[fast] != val) {
        nums[slow] = nums[fast];
        slow++;
    }
}
return slow;
```

四問：

1. `fast`：目前要檢查的位置。`slow`：**下一個該寫入的位置**，同時也等於「已經確定保留的元素個數」
2. **不變式：每輪開始時，`nums[0..slow-1]` 已經是 `nums[0..fast-1]` 裡所有不等於 val 的元素，順序不變**
3. `fast` 從 0 到 `nums.length - 1`，用 `<`
4. 結束時答案（長度）在 `slow`

注意第 1 問裡 `slow` 有**兩個身分**（下一個寫入位置＋已保留個數），這種「一個變數兩個意義」正是雙指標題的核心。寫下來才不會搞混。

## 第 3 問：迴圈條件與邊界

固定要回答三件事：

- **從哪開始**：`i = 0` 還是 `i = 1`？（看第 2 問的不變式一開始要成立）
- **到哪停**：`< length` 還是 `<= length - 1`？兩個等價，挑一個固定用
- **對撞指標**：`while (left < right)` 還是 `<=`？
  - `left < right`：中間那一格不處理。反轉、回文用這個
  - `left <= right`：中間那一格也要處理。二分搜尋用這個

寫下來，比在腦裡猜快得多。off-by-one 幾乎都死在這一問沒填。

---

## 第 4 問：結束時答案在哪個變數

聽起來廢話，但這是你反覆犯的錯：

- 樹題 543：`return` 回傳的是高度，答案在成員變數 `ans`
- 112：你以為要回傳「還剩多少」，其實要回傳「存不存在」
- 27：答案是 `slow`（長度），不是 `nums`

**先講清楚答案在哪，才知道迴圈裡要維護什麼。**

---

## 填不出第 2 問怎麼辦（照做，別坐著想）

1. 先寫暴力版，跑得動就好，O(n²) 沒關係
2. 拿一個 5 個元素的小例子，**在紙上畫表格**：每一輪的 `i`、每個變數的值
3. 看著表格問自己：「這個變數現在是什麼東西？」——用一句帶範圍的中文回答
4. 那句話就是不變式。填回第 2 問
5. 有了不變式，通常會發現暴力版的內層迴圈可以砍掉

第 2 步的表格是關鍵。**不要在腦裡跑迴圈，用手寫出來。**

## 常見不變式句型（照抄改字就好）

| pattern | 不變式長這樣 |
|---|---|
| 單指標累積 | `ans 是 nums[0..i-1] 的 ___（和／最大／計數）` |
| 快慢指標 | `nums[0..slow-1] 已經是處理好的結果，nums[slow..fast-1] 是要丟掉的` |
| 對撞指標 | `nums[0..left-1] 和 nums[right+1..n-1] 已經確定不影響答案` |
| 固定窗口 | `sum 是 nums[i-k+1..i] 的總和` |
| 可變窗口 | `nums[left..right] 是「以 right 結尾、還滿足條件」的最長區間` |
| 前綴和 | `leftSum 是 nums[0..i-1] 的總和` |
